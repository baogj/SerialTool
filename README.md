# SerialTool 串口调试助手

一个 Windows 桌面串口（COM 口）+ 网络（TCP / UDP）调试工具，C# .NET 8 WPF 编写，支持浅色 / 深色主题，单个 `SerialTool.exe`，**免安装、无需另装 .NET 运行库**，双击即可运行（Windows 10/11 x64）。

当前版本：**v1.5.0**

## 主要功能

**v1.5 新增一览**：多会话标签页（每个标签页一套独立的连接 + 收发界面）、批量测试用例（表格编辑 + 通过 / 失败报告，导出 HTML / CSV）、Modbus RTU ⇄ TCP 网关（双向）、Lua 脚本（MoonSharp，与原 DSL 脚本并列可选）。

**多会话标签页（v1.5，窗口顶部的「会话 1」「＋」）**
- 点「＋」新建一个会话标签页；标签上的「×」关闭该会话；**双击标签**（或右键 → 重命名）修改名称
- 每个新标签页都是独立会话：自己的连接（串口 / TCP 客户端 / TCP 服务器 / UDP）、接收区（文本 / HEX、时间戳、显示发送、编码、断帧、AT / Modbus RTU 着色）、发送区（HEX、转义、自动校验、行尾、定时发送）、自动回复（使用全局规则）、录制、收发计数，以及自己的脚本页（DSL 或 Lua）
- 标签页列表、名称和每个会话的全部设置随程序保存；升级前（v1.4 及以前）的单会话设置会自动迁移为第 1 个标签页「会话 1」，原有功能不受影响
- 第 1 个标签页就是原来的完整主界面（不能关闭，可以重命名）；「多端口」监视页保留不变
- 各功能在哪些标签页可用见下文「已知限制（v1.5）→ 功能范围」

**批量测试（v1.5，「扩展工具 → 批量测试」）**
- 表格里每一步：启用、名称、发送内容（文本支持 `\r\n` 转义，或勾 HEX）、自动校验（ModbusCrc16 / Crc16XModem / Crc16CcittFalse / Sum8 / Xor8）、判定方式、期望值、超时、延时、重试次数、失败后是否继续
- 判定方式：`Contains`（应答包含文本）、`Regex`（正则匹配）、`ExactHex`（应答字节完全一致，`??` 表示任意字节，如 `01 06 00 01 12 34 ?? ??`）、`ModbusValid`（合法 Modbus RTU 应答：CRC 正确、站号 / 功能码与请求一致、不是异常应答）、`None`（只发送不等待）
- 选择要测试的会话（任意标签页）和循环次数 →「运行」；运行中当前步骤标黄，通过标绿，失败标红；「停止」随时中断
- 测试用例保存为 JSON（「打开… / 保存…」），「示例」载入一份 AT + Modbus 的示例用例
- 源码包 `src/samples/示例测试用例.json` 是同一份示例，可直接「打开…」；`src/samples/*.lua` 是 Lua 示例脚本
- 运行结束后「导出 HTML…」「导出 CSV…」：每一步的时间戳、发送、收到、结果、耗时、说明、尝试次数，以及通过率汇总

**Modbus 网关（v1.5，「扩展工具 → Modbus 网关」）**
- **TCP→RTU**：本机作为 Modbus TCP 服务器（默认端口 502，可改），收到的 MBAP 请求去掉报文头、加 CRC 变成 RTU 帧发到所选会话（通常是接 RS-485 的串口），从站应答再还原成 MBAP、**保留原事务号**返回；多个 TCP 客户端的请求按顺序逐个上总线
- **RTU→TCP**：所选会话（串口）上的 RTU 主站发出的请求被转成 MBAP（自增事务号）发给远端 Modbus TCP 从站，按事务号匹配应答后加 CRC 写回串口
- 超时（默认 1000 ms）没有应答时返回 Modbus 异常 **0x0B（网关目标设备无响应）**；RTU 会话未连接 / 远端连不上时返回 **0x0A（网关路径不可用）**；广播（站号 0）只转发不等应答
- 「替换站号」非 0 时转发时改写站号；日志列出每个请求的事务号、站号、功能码、耗时、请求 / 应答 HEX，错误标红；顶部显示请求 / 应答 / 超时 / 异常 / 错误统计

**Lua 脚本（v1.5，「脚本」页的「脚本类型」选 Lua）**
- 使用 MoonSharp（Lua 5.2 语法），后台线程运行，「停止」可以中断死循环；出错时显示出错行号
- API：`send(str [, 校验])`、`sendhex(hex [, 校验])`、`read([超时ms [, 最少字节]])`、`waitfor(文本, 超时ms)`、`waitregex(正则, 超时ms)`、`sleep(ms)`、`log(...)` / `print(...)`、`crc16(data)`（Modbus，返回整数）、`crc16_ccitt(data [, 初值])`、`sum8`、`xor8`、`checksum(类型, data)`、`append_checksum(类型, data)`、`hex(data 或 数字 [, 位数])`、`unhex(hex)`、`text(data)`、`bytes(data)`、`clear()`、`now()`
- 校验类型名：`modbus` / `xmodem` / `ccitt` / `sum8` / `xor8`；收到的数据是“字节串”（每个字符一个字节，0~255），`text(data)` 按会话编码转成文字
- 回调：定义 `function on_receive(data) ... end` 后，每收到一包数据都会调用；脚本主体执行完后若定义了 on_receive，会继续运行等待数据直到点「停止」
- 状态：给全局变量 `status` 赋值（或 `set_status(x)`），脚本页顶部实时显示；`session.name`、`session.isopen()`、`session.send(...)`、`session.pending()` 访问所在会话
- 示例：「AT 示例」「Modbus 示例」（Lua 模式下载入 Lua 版本）、「回环示例」（on_receive）；其它标签页的脚本页用「插入示例…」下拉框

**自定义帧模板（v1.4，「扩展工具 → 帧解析」）**
- 「编辑模板…」打开模板编辑器，每个模板包含：
  - 帧头（HEX，必填，如 `AA 55`）、帧尾（可选，如 `0D 0A`）
  - 长度字段：偏移、字节数 1/2/4、大端/小端、长度值是否包含 帧头 / 长度字段本身 / 校验 / 帧尾，以及“修正”字节数；没有长度字段时可用“固定长度”或“以帧尾结束”
  - 校验：复用发送校验的算法（无 / Modbus CRC16 / CRC16-CCITT XModem / CCITT-FALSE / 累加和 / XOR），可设起始偏移，16 位校验可“字节交换”；校验字节位于帧尾之前（无帧尾时位于帧末）
  - 字段：名称、偏移（从帧头第一个字节算起）、类型 `U8 / I8 / U16 / I16 / U32 / I32 / Float / Bytes`、大端/小端、系数（如 0.1）、单位
  - 最大帧长、半帧超时（半帧超过时间未补齐就丢弃，重新同步）
- 编辑器底部可粘贴 HEX 测试数据，点「测试解析」立即看到拆帧与字段结果
- 勾「启用解析」后，主连接收到的数据（可选“含发送”）按模板流式拆帧：跨多个数据包的帧会自动拼接、帧前的垃圾字节自动跳过
- 结果表格：时间、方向、状态、每个字段一列（列头带单位）、原始帧；**校验错误 / 长度非法 / 帧尾不符的帧红色显示**并写明原因（如“校验错误：收到 C4，应为 C3”）；可勾「只看错误帧」，可「导出 CSV…」
- 模板保存在设置目录下的 `frame_templates.json`（首次启动自动生成一个示例模板“示例：AA55 温湿度帧”）

**Modbus 从站模拟（v1.4，「扩展工具 → Modbus 从站」）**
- 勾「启用从站模拟」后，主连接（串口 / TCP 服务器 / TCP 客户端 / UDP 均可）收到发给本站号的请求会自动应答
- 支持 01 读线圈、02 读离散输入、03 读保持寄存器、04 读输入寄存器、05 写单线圈、06 写单寄存器、0F 写多线圈、10 写多寄存器
- 帧格式 RTU（带 CRC）或 Modbus TCP（MBAP 头，事务号原样返回）；站号 1~247，0 号广播请求只执行不应答，其它站号的请求忽略
- 异常应答：不支持的功能码 → 01，地址越界 → 02，数量/数值/字节数非法 → 03；CRC 错误的请求不应答并计数
- 左侧可编辑数据表（地址 / 保持寄存器 / 输入寄存器 / 线圈 / 离散输入），寄存器可填十进制、`0x` 十六进制或负数；主站写入后表格自动刷新。「表大小」决定有效地址范围（默认 100，最大 10000）
- 右侧请求日志：时间、站号、说明（如“03 读保持寄存器 地址 0 数量 2”）、请求 HEX、应答 HEX，异常请求红色

**XModem / YModem 文件传输（v1.4，「扩展工具 → 文件传输」）**
- 协议：XModem（128 字节 + 校验和）、XModem（128 字节 + CRC16）、XModem-1K（1024 字节 + CRC16）、YModem（批量，块 0 携带文件名和大小，1K 块）
- 「选择文件…」（YModem 可多选批量发送）→「发送」；或设置接收目录 →「接收」（等待对方发送）
- 每块等待 ACK，NAK / 超时自动重发，最多 10 次；接收端校验错误会请求重发；YModem 按块 0 的文件大小截掉填充字节，XModem 去掉末尾 0x1A 填充
- 进度条、当前字节数、重试次数与日志；「取消」会向对方发送 CAN 序列，对方取消也能识别
- **传输期间自动暂停接收区显示、自动回复、Modbus 从站和串口转发**（字节计数照常），结束后恢复
- 接收的文件保存到“接收目录”（默认 `文档\SerialTool\received`），同名文件自动加序号；XModem 没有文件名，按时间命名

**会话录制与回放（v1.4，「扩展工具 → 录制回放」）**
- 「开始录制…」选择 `.jsonl` 文件后，把主连接的所有收发数据逐条写入：每行一个 JSON，如 `{"t":12.5,"dir":"rx","hex":"4F 4B 0D 0A","time":"2026-10-21T10:00:00.0125+08:00"}`（`t` 为距开始的毫秒数，网络连接还会记录来源地址 `src`）；「停止录制」后自动载入该文件以便回放
- 回放：「打开…」录制文件 → 选择
  - 回放到：**接收区显示**（按原方向显示，同时经过协议解析、帧解析、波形、曲线，不触发自动回复）或 **主连接发送**（把记录的数据从当前串口 / 网络发出，常用于模拟设备）
  - 内容：全部 / 仅接收 RX / 仅发送 TX
  - 速度：0.5x / 1x（原始节奏）/ 2x / 最快，可在回放过程中切换
- 「暂停 / 继续」「停止」，进度条显示已回放条数

**波特率自动识别（v1.4，「连接设置 → 波特率 → 识别」）**
- 选好串口后点「识别」（若该串口已打开会提示先关闭），依次用 1200 ~ 921600 共 12 种波特率（可取消勾选）打开串口监听设备输出，数据位 / 校验 / 停止位取自主界面
- 可选每个波特率先发送探测命令（默认 `AT\r\n`，支持转义），监听时间默认 600 ms
- 按 可打印字符比例、字母数字比例、CRLF、`00/FF` 帧错误特征、合法 UTF-8 中文 等打分（0~100），表格列出每个波特率的字节数、得分、说明和数据预览，自动选出最佳结果
- 「应用」把结果填入波特率；「应用并打开」直接打开串口；双击表格行可手动选择

**连接类型（v1.3）**
- 左侧「连接设置 → 类型」：`串口` / `TCP 客户端` / `TCP 服务器` / `UDP`，选中的就是“主连接”
- 主连接上的一切功能都通用：发送 / 定时发送 / 快捷指令 / 历史、自动校验、关键字高亮与自动回复、脚本、AT / Modbus 解析、波形、曲线、吞吐统计、Modbus 主站、导出 CSV
- **TCP 客户端**：填远程主机、端口 →「连接」；对方断开会在状态栏提示
- **TCP 服务器**：填本地端口 →「开始监听」；下方列出已连接的客户端（可多个），默认发给全部客户端，勾选“只发送给选中的客户端”后只发给列表中选中的；「断开选中」可踢掉客户端。开启“显示发送 / 时间戳”时，每行带客户端地址前缀 `[192.168.1.5:50123]`
- **UDP**：本地端口（0 = 系统分配）+ 远程主机:端口；远程地址留空时自动回复最后一个来包的地址
- 自动重连只对串口有效

**Modbus 主站（v1.3，「Modbus 主站」页）**
- 从站地址、功能码（01/02/03/04 读，05/06 写单个，0F/10 写多个）、起始地址、数量、写入值、超时
- 「读取 / 写入」：自动组帧（RTU 自动加 CRC），经主连接发出，等待应答并解析；表格显示 地址 / 地址(Hex) / 原始值 / 显示值
- 显示格式：UInt16 / Int16 / Hex / Binary，以及跨两个寄存器的 Int32 / UInt32 / Float32，字节序 ABCD / CDAB / BADC / DCBA（切换格式会立即重新解析上一次结果）
- 写入值：逗号或空格分隔，支持十进制、`0x` 十六进制、负数；选 Float32 等 32 位格式后用 10 写多个寄存器，每个值自动拆成两个寄存器；线圈写 `1/0` 或 `ON/OFF`
- 异常应答醒目红色提示（如“异常码 02 — 非法数据地址”）；状态栏统计 成功 / 超时 / CRC错 / 异常
- 可选轮询周期；帧格式可切换 **RTU** 或 **Modbus TCP（MBAP 头）**，TCP 客户端直连 Modbus TCP 设备时选后者
- 请求与应答同时出现在「接收」页（协议选“Modbus RTU”时还会逐帧解析）

**串口转发（v1.3，「串口转发」页）**
- 把主连接（通常是串口）与一个网络端点双向透传：网络端可选 TCP 服务器（等别人连入）/ TCP 客户端 / UDP
- 主连接收到的数据 → 发往网络；网络收到的数据 → 写入主连接（在接收区显示为“发送”）
- 实时显示 主连接→网络 / 网络→主连接 / 丢弃 字节数；主连接断开或自动重连期间转发保持运行

**多端口监视（v1.3，「多端口」页）**
- 「+ 添加端口」可加任意多个串口，每个有自己的别名、端口、波特率、格式（8N1/8E1/8O1/8N2/7E1…）、HEX 显示，单独打开 / 关闭，或「全部打开 / 全部关闭」
- 所有端口的收发合并显示在一个列表里：`[时间] [别名] 收← 内容`，每个端口一种颜色（点色块切换）
- 底部选择目标端口发送（使用左侧“发送设置”的转义、校验和行尾）
- 端口列表会保存，下次启动自动恢复（不会自动打开）
- 说明：选择了“多端口监视页”方案而不是“每个会话一整套界面的标签页”，原因见文末“已知限制”

**查找与过滤（v1.3）**
- 接收页按 **Ctrl+F**（或标题栏「查找」）打开查找栏：支持正则、区分大小写，Enter / Shift+Enter 或 ↑↓ 按钮跳到下一个 / 上一个，显示“第 i / 共 N 处”
- 行视图（AT / Modbus / 高亮 / 过滤）中所有匹配处以橙色背景高亮，跳转时选中所在行并暂停自动滚动；普通文本视图中选中当前匹配
- 勾选「过滤」：只显示匹配行，或切到“隐藏匹配行”；普通文本视图会自动切换为行视图。点「清除」或 Esc 恢复全部行

**导出 CSV（v1.3）**
- 「接收设置 → 导出 CSV…」：按行导出收发数据，列为 时间、方向、来源、字节数、HEX、文本（UTF-8 带 BOM，Excel 直接打开）
- 按 `\n` 分行；没有换行的数据（如 HEX 协议）按静默间隔（分帧时间，至少 50 ms）成行；与显示设置无关，最多保留最近 20 万行；「清空接收」同时清空

**数值曲线（v1.3，「曲线」页）**
- 自动从接收的文本行里解析数字：`temp=23.5,hum=40`、`T: -1.5 P = 1013` 这类“名称=值 / 名称:值”按名称成通道；`1.2, 3.4 5` 这类纯数字按顺序成 CH1、CH2…
- 多通道滚动曲线 + 图例（显示最新值），Y 轴自动缩放；可暂停、清空，窗口 100~10000 个样本
- 「导出 CSV…」导出曲线数据（时间 + 每个通道一列）

**串口设置**
- 串口列表自动显示设备名称（如 `COM3  USB-SERIAL CH340`），每秒自动检测插拔，也可点“刷新”或按 F5
- 波特率：常用预设（110 ~ 3000000），也可直接输入自定义值（回车生效）
- 数据位 5/6/7/8，停止位 1/1.5/2，校验 无/奇/偶/标记/空格
- 流控：无 / RTS-CTS / XON-XOFF / 两者同时
- DTR、RTS 手动开关（启用 RTS/CTS 流控时 RTS 由硬件自动控制）
- 串口打开后修改波特率等参数会立即生效，无需重新打开
- “自动重连”：设备被拔出后自动关闭，重新插回时自动打开

**接收**
- 文本 / HEX 显示，可选时间戳（精确到毫秒）、显示发送内容（`发→` / `收←`）
- “分帧”：开启时间戳或显示发送时，数据间隔超过设定毫秒数或遇到换行就另起一行
- 编码：UTF-8 / GBK / ASCII（多字节汉字被拆成两包也能正确显示）
- 自动滚动、暂停显示（暂停期间数据会缓存，取消暂停后补上）、清空
- “保存接收…”把当前接收区保存为文本；“记录到文件”把显示内容实时追加写入日志
- 接收区最多保留约 150 万字符，超出后自动裁掉最早的内容，长时间运行不卡顿

**协议解析（v1.1）**
- 左侧「协议」下拉：`普通` / `AT` / `Modbus RTU`
- **AT**：按行着色——命令（青）、OK（绿）、ERROR/BUSY/+CME（红）、+URC（黄）；虚拟化列表，高波特率下仍流畅
- **Modbus RTU**：流式帧检测 + CRC16 校验，显示地址、功能码、长度、CRC✓/✗；正确帧绿色、错误帧红色；状态栏统计帧 OK/ERR
- 协议模式与 HEX/文本显示互为切换视图（选协议时用着色列表，选普通时用原 TextBox）

**字节流波形（v1.1）**
- 顶部「波形」页：把最近 RX（可选 TX）字节画成滚动条带图，Y 轴 0–255
- 暂停、清空、窗口长度 256–8192 可调；纯 WPF 绘制，无额外依赖
- 与接收刷新同路径批量更新，不卡 UI

**脚本自动化（v1.1）**
- 「脚本」页：内置轻量命令语言（无 Roslyn/Lua 依赖，单文件体积小）
- 命令：`SEND` / `SENDHEX` / `SENDHEXRAW` / `CHECKSUM` / `SLEEP` / `WAITFOR` / `WAITREGEX` / `LOG` / `CLEARRX` / `STATUS`，`#` 注释
- `SEND 文本`：追加校验 + 行尾；`SENDHEX AA BB`：追加校验（不加行尾）；`SENDHEXRAW AA BB`：原样发送
- `CHECKSUM MODBUS`：本脚本后续发送使用指定校验（`NONE` / `MODBUS` / `XMODEM` / `CCITT` / `SUM` / `XOR`），`CHECKSUM DEFAULT` 恢复跟随界面设置
- `WAITFOR` 只匹配接收到的数据（v1.1 会误匹配自己发出的回显，已修复）
- 后台线程运行，可随时停止；提供 AT 轮询、Modbus 读保持寄存器示例按钮
- `SEND` 支持 `\r \n \t \0 \\ \xHH` 转义

**吞吐率与统计（v1.1）**
- 状态栏：瞬时 RX/TX 速率（1 秒窗口）、峰值、会话时长、总字节数
- Modbus 模式下额外显示帧 OK/ERR 计数
- 「计数清零」同时重置字节计数与吞吐/会话统计

**发送自动校验（v1.2）**
- 「发送设置 → 校验」：`无` / `Modbus CRC16（低字节在前）` / `CRC16-CCITT (XModem, 初值 0)` / `CRC16-CCITT-FALSE (初值 FFFF)` / `累加和 (8 位)` / `XOR 异或`
- 顺序：**内容 → 校验 → 行尾**（校验只对内容本身计算，行尾在校验之后追加，未选行尾就不加）
- 对手动发送、定时发送、快捷指令、自动回复、脚本 `SEND` / `SENDHEX` 都生效（“发送文件”保持原样，不加校验）
- 两个 CRC16-CCITT 按惯例高字节在前，Modbus CRC 低字节在前
- 勾选“显示发送”时，文本回显里校验字节以 `[C5 CD]` 形式标出；HEX 显示时就是帧尾的字节
- 下拉框下方实时显示当前发送区内容的校验值（鼠标悬停看完整的实际发送字节）；「计算器…」同时列出所有算法的结果，可复制

**关键字高亮 + 自动回复（v1.2）**
- 「接收设置」里的 `关键字高亮`、`自动回复` 两个开关，`规则…` 打开规则表（与快捷指令类似，可添加/删除/排序）
- 每条规则：启用、名称、匹配内容（文本 / 正则 / HEX 字节，可忽略大小写）、高亮颜色、自动回复内容（文本或 HEX）、延时 ms、冷却 ms
- 高亮：匹配到的文字加背景色，普通 / AT / Modbus 视图都支持。普通模式下开启高亮后，接收区切换为同样的虚拟化着色行视图（关闭高亮即恢复原文本框，内容会保留）
- 行视图里可 Shift/Ctrl 多选行，Ctrl+C 或右键“复制选中行 / 复制全部”
- 自动回复：收到匹配内容后按延时发送回复（会追加当前校验和行尾）。同一段数据只触发一次；每条规则有冷却时间；全局每秒最多 20 次，防止两台设备互相回复造成死循环；状态栏显示回复次数
- 规则表下方可输入测试文本，点“测试”看哪些规则会命中；保存时会检查正则 / HEX 格式
- 规则和开关都会保存

**主题（v1.2）**
- 右上角「主题」：`浅色` / `深色` / `跟随系统`（跟随 Windows“应用模式”，系统切换时自动跟着变）
- 整个窗口都跟随主题，包括接收区、波形、脚本、状态栏、下拉框、滚动条、对话框和标题栏（Windows 10 2004+/11）

**协议选择更方便（v1.2）**
- 接收页标题栏左侧新增「协议」下拉框，与左侧接收设置里的保持同步

**发送**
- 文本 / HEX 发送（HEX 支持 `AA 55 01`、`AA5501`、`0xAA,0x55` 等写法）；切换模式时自动转换发送区内容
- 行尾自动追加：无 / `\r` / `\n` / `\r\n`（对文本、HEX、快捷指令都生效）
- “解析转义符”：文本中可写 `\r \n \t \0 \\ \xHH`
- 发送按钮或 **Ctrl+Enter** 发送；定时（周期）发送，周期单位 ms（最小 10 ms）
- 发送历史（最近 50 条，下拉选择即可重新填入）
- 快捷指令按钮：点“编辑快捷指令…”自定义名称、内容、是否 HEX，可排序，自动保存
- 发送文件：把任意文件的原始字节发出去（≤16 MB）

**其他**
- 读写都在后台线程进行，界面每 50 ms 批量刷新一次，高波特率下也不卡
- 设备被拔出、读写出错时会自动关闭串口并在状态栏提示，不会崩溃

## 新功能简要用法

**v1.5**
1. **多会话**：点顶部「＋」→ 新标签页左侧选 COM4（或 TCP 客户端）→「打开」；「会话 1」仍然是原来的主界面。双击标签改名为「PLC」「仪表」等，关闭程序后会记住。
2. **批量测试**：「扩展工具 → 批量测试」→「示例」→ 会话选要测的标签页、循环 10 →「运行」；结束后「导出 HTML…」得到带通过率的报告。
3. **Modbus 网关**：在某个标签页打开接 RS-485 的串口（如 COM3 9600 8N1）→「扩展工具 → Modbus 网关」方向选 TCP→RTU、RTU 会话选该标签页、端口 502 →「启动网关」；上位机用 Modbus TCP 连 `本机IP:502` 即可读写串口上的从站。
4. **Lua**：「脚本」页「脚本类型」选 Lua →「Modbus 示例」→「运行」；或写：
   ```lua
   send("AT\r\n")
   if waitfor("OK", 1000) then log("模块正常") else log("无应答") end
   local crc = crc16(unhex("01 03 00 00 00 01"))   -- 0x0A84
   sendhex("01 03 00 00 00 01", "modbus")          -- 自动追加 CRC
   ```


**v1.4**
1. **帧模板**：「扩展工具 → 帧解析」→ 勾「启用解析」，模板选“示例：AA55 温湿度帧”；设备发 `AA 55 05 01 00 FA 01 C2 C3` 时表格显示 命令=1、温度=25 ℃、湿度=45 %；把最后一个字节改错就会显示红色“校验错误”。自己的协议点「编辑模板…」新建，粘贴一帧 HEX 点「测试解析」调试。
2. **Modbus 从站**：打开串口（或类型选 TCP 服务器、端口 502 并把帧格式切到 Modbus TCP）→「扩展工具 → Modbus 从站」站号 1、填几个保持寄存器 → 勾「启用从站模拟」；用 Modbus Poll 等主站软件读写即可，日志里能看到每个请求和应答。
3. **YModem 发送固件**：打开串口 →「扩展工具 → 文件传输」协议选 YModem →「选择文件…」→ 让设备进入 YModem 接收（出现 `CCC…`）→「发送」。接收则点「接收」后让对方开始发送。
4. **录制回放**：「扩展工具 → 录制回放」→「开始录制…」，正常调试一段时间后「停止录制」；之后「开始回放」即可按原节奏在接收区重现，或选“主连接发送 + 仅接收 RX”把设备输出重新发给上位机。
5. **波特率识别**：选串口 → 点波特率旁的「识别」→「开始识别」，等表格出结果后点「应用并打开」。

**v1.3**
1. **TCP 调试**：类型选「TCP 服务器」，本地端口 8080 →「开始监听」；用别的工具连上后即可收发。选「TCP 客户端」填 IP / 端口 →「连接」。
2. **Modbus 主站**：打开串口（如 9600 8N1）→「Modbus 主站」页，从站 1、功能 03、起始 0、数量 10 →「读取」。读浮点：数量 2，显示 Float32，字节序按设备文档选。
3. **串口转发**：先打开串口 →「串口转发」页，网络端选 TCP 服务器、本地端口 9000 →「启动转发」，其它电脑连 `本机IP:9000` 即可透传串口。
4. **多端口**：「多端口」页 →「+ 添加端口」两次，分别选 COM3 / COM4 →「全部打开」。
5. **查找过滤**：接收页 Ctrl+F 输入 `ERROR`，勾「过滤」只看错误行。
6. **曲线**：设备每行打印 `temp=23.5,hum=40`，切到「曲线」页即可看到两条曲线。


**v1.2**
1. **自动校验**：校验选「Modbus CRC16」，HEX 发送 `01 03 00 00 00 0A`，实际发出 `01 03 00 00 00 0A C5 CD`。
2. **高亮**：勾「关键字高亮」→「规则…」添加，比如匹配 `ERROR` 红色；收到时整段标红。
3. **自动回复**：规则里匹配 `PING`、勾自动回复、回复内容 `PONG`、冷却 1000；再勾左侧「自动回复」。
4. **主题**：右上角切换浅色 / 深色 / 跟随系统。

**v1.1**

1. **AT 着色**：协议选「AT」，打开串口后发 `AT`，回显里 OK/ERROR 会着色。
2. **Modbus**：协议选「Modbus RTU」，用 HEX 发送完整帧（含 CRC），接收区会拆帧并标 CRC 结果。
3. **波形**：切到「波形」页，有数据进来即可看到蓝色 RX 曲线（可选绿色 TX）。
4. **脚本**：切到「脚本」页 →「AT 示例」→「运行」；需先打开串口。`WAITFOR OK 2000` 表示最多等 2 秒直到接收缓冲出现 `OK`。
5. **吞吐**：打开串口后状态栏右侧自动刷新速率；「计数清零」重置。

- 第 1 个标签页不能关闭；关闭其它标签页会断开其连接并停止其脚本；若该会话正被网关使用，网关一并停止
- 同一个会话可以同时被脚本、批量测试、网关使用，它们都会收到同样的数据并各自发送，需自行避免同时使用
- 批量测试一次只运行一个用例；“ExactHex”要求应答恰好等于期望长度，多出的字节判失败；“ModbusValid”只校验 RTU 帧（Modbus TCP 设备请用 Contains / ExactHex）；超时计时从发送完成开始，串口很慢时请适当加大
- 网关同一时间只运行一个（一个方向）；TCP→RTU 方向所有客户端共用一条 RTU 总线，请求严格串行，吞吐受串口速率限制；RTU→TCP 方向按功能码推算请求长度，未知功能码靠 CRC 搜索定界；不支持 Modbus ASCII
- Lua 为 MoonSharp 实现的 Lua 5.2（无 `//` 整除、无 `utf8` 库），沙箱模式（无 `io` / `os.execute` / `require` 文件加载）；`on_receive` 在脚本线程上调用（在 `sleep` / `read` / `waitfor` 期间或主体结束后），回调里不要长时间阻塞；`waitfor` 按字节匹配，`waitregex` 按会话编码解码后匹配
- 脚本里收到的数据是字节串；发送含中文的字符串时按会话编码转换，只含 0~255 字符的字符串按原字节发送

## 已知限制（v1.4）

- 帧模板：长度字段最多 4 字节、只支持一种帧头；字段偏移是相对帧头起点的固定偏移（不支持可变长度字段后再跟字段、位域、BCD、字符串编码）；表格最多保留最近 5000 帧
- 帧模板的校验字节固定位于帧尾之前（或帧末），不支持校验在帧中间的协议
- Modbus 从站只模拟一个站号（数据表所有区共用同一个“表大小”）；未实现 07/08/11/16/17/2B 等诊断与其它功能码（返回异常 01）；RTU 下不支持的功能码请求需要靠 CRC 搜索定位，串口上与其它从站共线时可能需要一帧时间重新同步
- XModem / YModem 通过主连接的发送队列收发，串口极慢（如 1200 波特 + 1K 块）时每块超时为 10 秒；未实现 YModem-G / ZModem；XModem 接收会去掉文件末尾的 0x1A 填充（若原文件本身以 0x1A 结尾会被截掉，YModem 有文件大小不受影响）
- 文件传输期间整个主连接被独占：接收区显示、自动回复、从站、转发、脚本暂停；多端口页的端口不受影响
- 回放“最快”速度到接收区时受界面刷新（每 50 ms 批量）限制，大文件需要一定时间；回放到主连接时按 TX 队列节流
- 波特率识别依赖设备在监听期间有输出（或回应探测命令）；纯二进制、数据很少或格式（数据位 / 校验）不同的设备可能得分都不高，此时表格仍可手动选择；识别期间该串口不能被其它程序占用
- 窗口内容在个别显卡 / 远程环境下截图或显示为空白时，可用 `--software-render` 启动

## 已知限制（v1.3）

- 多会话采用「多端口监视」页而非“每个会话一整套界面”的标签页：主界面的发送、脚本、自动回复、Modbus 主站、波形、曲线等都绑定在一个主连接上，整体复制成多标签风险大、容易出错；多端口页可同时打开任意多个串口、合并着色显示并选择端口发送，但多端口里的端口不参与脚本 / 自动回复 / Modbus 主站 / 曲线（这些只用主连接）
- 普通文本视图中的查找只选中当前匹配（无法给 TextBox 内所有匹配上色）；开启过滤或高亮后的行视图会高亮全部匹配
- Modbus 主站一次只执行一个请求；RTU 透传 TCP/UDP 时按 RTU 帧解析，直连 Modbus TCP 设备需把帧格式切到“Modbus TCP”
- 曲线只解析主连接收到的文本行（每行最多 16 个通道）；HEX / 二进制协议的数据请用 Modbus 主站或波形
- 串口转发是纯透传，不做协议转换（如 Modbus TCP ↔ RTU）
- UDP 单包最大 65507 字节，超过会自动分包
