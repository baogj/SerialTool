# SerialTool 串口调试助手

一个 Windows 桌面串口（COM 口）+ 网络（TCP / UDP）调试工具，C# .NET 8 WPF 编写，支持浅色 / 深色主题，单个 `SerialTool.exe`，**免安装、无需另装 .NET 运行库**，双击即可运行（Windows 10/11 x64）。

当前版本：**v1.3.0**

## 主要功能

**v1.3 新增一览**：Modbus 主站、TCP 客户端 / TCP 服务器 / UDP 网络调试、串口转发（串口 ⇄ 网络）、多端口同时监视、接收区查找与过滤（Ctrl+F）、导出 CSV、数值曲线。

**连接类型（v1.3）**
- 左侧「连接设置 → 类型」：`串口` / `TCP 客户端` / `TCP 服务器` / `UDP`，选中的就是“主连接”
- 主连接上的一切功能都通用：发送 / 定时发送 / 快捷指令 / 历史、自动校验、关键字高亮与自动回复、脚本、AT / Modbus 解析、波形、曲线、吞吐统计、Modbus 主站、导出 CSV
- **TCP 客户端**：填远程主机、端口 →「连接」；对方断开会在状态栏提示
- **TCP 服务器**：填本地端口 →「开始监听」；下方列出已连接的客户端（可多个），默认发给全部客户端，勾选“只发送给选中的客户端”后只发给列表中选中的；「断开选中」可踢掉客户端。开启“显示发送 / 时间戳”时，每行带客户端地址前缀 `[192.168.1.5:50123]`
- **UDP**：本地端口（0 = 系统分配）+ 远程主机:端口；远程地址留空时自动回复最后一个来包的地址
- 自动重连只对串口有效

**Modbus 主站（v1.3，「Modbus 主站」页）**
- 从站地址、功能码（01/02/03/04 读，05/06 写单个，0F/10 写多个）、起始地址、数量、写入值、超时
- 「读取 / 写入」：自动组帧（RTU 自动加 CRC），经主连接发出，等待应答并解析；表格显示 地址 / 地址(Hex) / 原始值 / 显示值
- 显示格式：UInt16 / Int16 / Hex / Binary，以及跨两个寄存器的 Int32 / UInt32 / Float32，字节序 ABCD / CDAB / BADC / DCBA（切换格式会立即重新解析上一次结果）
- 写入值：逗号或空格分隔，支持十进制、`0x` 十六进制、负数；选 Float32 等 32 位格式后用 10 写多个寄存器，每个值自动拆成两个寄存器；线圈写 `1/0` 或 `ON/OFF`
- 异常应答醒目红色提示（如“异常码 02 — 非法数据地址”）；状态栏统计 成功 / 超时 / CRC错 / 异常
- 可选轮询周期；帧格式可切换 **RTU** 或 **Modbus TCP（MBAP 头）**，TCP 客户端直连 Modbus TCP 设备时选后者
- 请求与应答同时出现在「接收」页（协议选“Modbus RTU”时还会逐帧解析）

**串口转发（v1.3，「串口转发」页）**
- 把主连接（通常是串口）与一个网络端点双向透传：网络端可选 TCP 服务器（等别人连入）/ TCP 客户端 / UDP
- 主连接收到的数据 → 发往网络；网络收到的数据 → 写入主连接（在接收区显示为“发送”）
- 实时显示 主连接→网络 / 网络→主连接 / 丢弃 字节数；主连接断开或自动重连期间转发保持运行

**多端口监视（v1.3，「多端口」页）**
- 「+ 添加端口」可加任意多个串口，每个有自己的别名、端口、波特率、格式（8N1/8E1/8O1/8N2/7E1…）、HEX 显示，单独打开 / 关闭，或「全部打开 / 全部关闭」
- 所有端口的收发合并显示在一个列表里：`[时间] [别名] 收← 内容`，每个端口一种颜色（点色块切换）
- 底部选择目标端口发送（使用左侧“发送设置”的转义、校验和行尾）
- 端口列表会保存，下次启动自动恢复（不会自动打开）
- 说明：选择了“多端口监视页”方案而不是“每个会话一整套界面的标签页”，原因见文末“已知限制”

**查找与过滤（v1.3）**
- 接收页按 **Ctrl+F**（或标题栏「查找」）打开查找栏：支持正则、区分大小写，Enter / Shift+Enter 或 ↑↓ 按钮跳到下一个 / 上一个，显示“第 i / 共 N 处”
- 行视图（AT / Modbus / 高亮 / 过滤）中所有匹配处以橙色背景高亮，跳转时选中所在行并暂停自动滚动；普通文本视图中选中当前匹配
- 勾选「过滤」：只显示匹配行，或切到“隐藏匹配行”；普通文本视图会自动切换为行视图。点「清除」或 Esc 恢复全部行

**导出 CSV（v1.3）**
- 「接收设置 → 导出 CSV…」：按行导出收发数据，列为 时间、方向、来源、字节数、HEX、文本（UTF-8 带 BOM，Excel 直接打开）
- 按 `\n` 分行；没有换行的数据（如 HEX 协议）按静默间隔（分帧时间，至少 50 ms）成行；与显示设置无关，最多保留最近 20 万行；「清空接收」同时清空

**数值曲线（v1.3，「曲线」页）**
- 自动从接收的文本行里解析数字：`temp=23.5,hum=40`、`T: -1.5 P = 1013` 这类“名称=值 / 名称:值”按名称成通道；`1.2, 3.4 5` 这类纯数字按顺序成 CH1、CH2…
- 多通道滚动曲线 + 图例（显示最新值），Y 轴自动缩放；可暂停、清空，窗口 100~10000 个样本
- 「导出 CSV…」导出曲线数据（时间 + 每个通道一列）

**串口设置**
- 串口列表自动显示设备名称（如 `COM3  USB-SERIAL CH340`），每秒自动检测插拔，也可点“刷新”或按 F5
- 波特率：常用预设（110 ~ 3000000），也可直接输入自定义值（回车生效）
- 数据位 5/6/7/8，停止位 1/1.5/2，校验 无/奇/偶/标记/空格
- 流控：无 / RTS-CTS / XON-XOFF / 两者同时
- DTR、RTS 手动开关（启用 RTS/CTS 流控时 RTS 由硬件自动控制）
- 串口打开后修改波特率等参数会立即生效，无需重新打开
- “自动重连”：设备被拔出后自动关闭，重新插回时自动打开

**接收**
- 文本 / HEX 显示，可选时间戳（精确到毫秒）、显示发送内容（`发→` / `收←`）
- “分帧”：开启时间戳或显示发送时，数据间隔超过设定毫秒数或遇到换行就另起一行
- 编码：UTF-8 / GBK / ASCII（多字节汉字被拆成两包也能正确显示）
- 自动滚动、暂停显示（暂停期间数据会缓存，取消暂停后补上）、清空
- “保存接收…”把当前接收区保存为文本；“记录到文件”把显示内容实时追加写入日志
- 接收区最多保留约 150 万字符，超出后自动裁掉最早的内容，长时间运行不卡顿

**协议解析（v1.1）**
- 左侧「协议」下拉：`普通` / `AT` / `Modbus RTU`
- **AT**：按行着色——命令（青）、OK（绿）、ERROR/BUSY/+CME（红）、+URC（黄）；虚拟化列表，高波特率下仍流畅
- **Modbus RTU**：流式帧检测 + CRC16 校验，显示地址、功能码、长度、CRC✓/✗；正确帧绿色、错误帧红色；状态栏统计帧 OK/ERR
- 协议模式与 HEX/文本显示互为切换视图（选协议时用着色列表，选普通时用原 TextBox）

**字节流波形（v1.1）**
- 顶部「波形」页：把最近 RX（可选 TX）字节画成滚动条带图，Y 轴 0–255
- 暂停、清空、窗口长度 256–8192 可调；纯 WPF 绘制，无额外依赖
- 与接收刷新同路径批量更新，不卡 UI

**脚本自动化（v1.1）**
- 「脚本」页：内置轻量命令语言（无 Roslyn/Lua 依赖，单文件体积小）
- 命令：`SEND` / `SENDHEX` / `SENDHEXRAW` / `CHECKSUM` / `SLEEP` / `WAITFOR` / `WAITREGEX` / `LOG` / `CLEARRX` / `STATUS`，`#` 注释
- `SEND 文本`：追加校验 + 行尾；`SENDHEX AA BB`：追加校验（不加行尾）；`SENDHEXRAW AA BB`：原样发送
- `CHECKSUM MODBUS`：本脚本后续发送使用指定校验（`NONE` / `MODBUS` / `XMODEM` / `CCITT` / `SUM` / `XOR`），`CHECKSUM DEFAULT` 恢复跟随界面设置
- `WAITFOR` 只匹配接收到的数据（v1.1 会误匹配自己发出的回显，已修复）
- 后台线程运行，可随时停止；提供 AT 轮询、Modbus 读保持寄存器示例按钮
- `SEND` 支持 `\r \n \t \0 \\ \xHH` 转义

**吞吐率与统计（v1.1）**
- 状态栏：瞬时 RX/TX 速率（1 秒窗口）、峰值、会话时长、总字节数
- Modbus 模式下额外显示帧 OK/ERR 计数
- 「计数清零」同时重置字节计数与吞吐/会话统计

**发送自动校验（v1.2）**
- 「发送设置 → 校验」：`无` / `Modbus CRC16（低字节在前）` / `CRC16-CCITT (XModem, 初值 0)` / `CRC16-CCITT-FALSE (初值 FFFF)` / `累加和 (8 位)` / `XOR 异或`
- 顺序：**内容 → 校验 → 行尾**（校验只对内容本身计算，行尾在校验之后追加，未选行尾就不加）
- 对手动发送、定时发送、快捷指令、自动回复、脚本 `SEND` / `SENDHEX` 都生效（“发送文件”保持原样，不加校验）
- 两个 CRC16-CCITT 按惯例高字节在前，Modbus CRC 低字节在前
- 勾选“显示发送”时，文本回显里校验字节以 `[C5 CD]` 形式标出；HEX 显示时就是帧尾的字节
- 下拉框下方实时显示当前发送区内容的校验值（鼠标悬停看完整的实际发送字节）；「计算器…」同时列出所有算法的结果，可复制

**关键字高亮 + 自动回复（v1.2）**
- 「接收设置」里的 `关键字高亮`、`自动回复` 两个开关，`规则…` 打开规则表（与快捷指令类似，可添加/删除/排序）
- 每条规则：启用、名称、匹配内容（文本 / 正则 / HEX 字节，可忽略大小写）、高亮颜色、自动回复内容（文本或 HEX）、延时 ms、冷却 ms
- 高亮：匹配到的文字加背景色，普通 / AT / Modbus 视图都支持。普通模式下开启高亮后，接收区切换为同样的虚拟化着色行视图（关闭高亮即恢复原文本框，内容会保留）
- 行视图里可 Shift/Ctrl 多选行，Ctrl+C 或右键“复制选中行 / 复制全部”
- 自动回复：收到匹配内容后按延时发送回复（会追加当前校验和行尾）。同一段数据只触发一次；每条规则有冷却时间；全局每秒最多 20 次，防止两台设备互相回复造成死循环；状态栏显示回复次数
- 规则表下方可输入测试文本，点“测试”看哪些规则会命中；保存时会检查正则 / HEX 格式
- 规则和开关都会保存

**主题（v1.2）**
- 右上角「主题」：`浅色` / `深色` / `跟随系统`（跟随 Windows“应用模式”，系统切换时自动跟着变）
- 整个窗口都跟随主题，包括接收区、波形、脚本、状态栏、下拉框、滚动条、对话框和标题栏（Windows 10 2004+/11）

**协议选择更方便（v1.2）**
- 接收页标题栏左侧新增「协议」下拉框，与左侧接收设置里的保持同步

**发送**
- 文本 / HEX 发送（HEX 支持 `AA 55 01`、`AA5501`、`0xAA,0x55` 等写法）；切换模式时自动转换发送区内容
- 行尾自动追加：无 / `\r` / `\n` / `\r\n`（对文本、HEX、快捷指令都生效）
- “解析转义符”：文本中可写 `\r \n \t \0 \\ \xHH`
- 发送按钮或 **Ctrl+Enter** 发送；定时（周期）发送，周期单位 ms（最小 10 ms）
- 发送历史（最近 50 条，下拉选择即可重新填入）
- 快捷指令按钮：点“编辑快捷指令…”自定义名称、内容、是否 HEX，可排序，自动保存
- 发送文件：把任意文件的原始字节发出去（≤16 MB）

**其他**
- 读写都在后台线程进行，界面每 50 ms 批量刷新一次，高波特率下也不卡
- 设备被拔出、读写出错时会自动关闭串口并在状态栏提示，不会崩溃

## 新功能简要用法

**v1.3**
1. **TCP 调试**：类型选「TCP 服务器」，本地端口 8080 →「开始监听」；用别的工具连上后即可收发。选「TCP 客户端」填 IP / 端口 →「连接」。
2. **Modbus 主站**：打开串口（如 9600 8N1）→「Modbus 主站」页，从站 1、功能 03、起始 0、数量 10 →「读取」。读浮点：数量 2，显示 Float32，字节序按设备文档选。
3. **串口转发**：先打开串口 →「串口转发」页，网络端选 TCP 服务器、本地端口 9000 →「启动转发」，其它电脑连 `本机IP:9000` 即可透传串口。
4. **多端口**：「多端口」页 →「+ 添加端口」两次，分别选 COM3 / COM4 →「全部打开」。
5. **查找过滤**：接收页 Ctrl+F 输入 `ERROR`，勾「过滤」只看错误行。
6. **曲线**：设备每行打印 `temp=23.5,hum=40`，切到「曲线」页即可看到两条曲线。


**v1.2**
1. **自动校验**：校验选「Modbus CRC16」，HEX 发送 `01 03 00 00 00 0A`，实际发出 `01 03 00 00 00 0A C5 CD`。
2. **高亮**：勾「关键字高亮」→「规则…」添加，比如匹配 `ERROR` 红色；收到时整段标红。
3. **自动回复**：规则里匹配 `PING`、勾自动回复、回复内容 `PONG`、冷却 1000；再勾左侧「自动回复」。
4. **主题**：右上角切换浅色 / 深色 / 跟随系统。

**v1.1**

1. **AT 着色**：协议选「AT」，打开串口后发 `AT`，回显里 OK/ERROR 会着色。
2. **Modbus**：协议选「Modbus RTU」，用 HEX 发送完整帧（含 CRC），接收区会拆帧并标 CRC 结果。
3. **波形**：切到「波形」页，有数据进来即可看到蓝色 RX 曲线（可选绿色 TX）。
4. **脚本**：切到「脚本」页 →「AT 示例」→「运行」；需先打开串口。`WAITFOR OK 2000` 表示最多等 2 秒直到接收缓冲出现 `OK`。
5. **吞吐**：打开串口后状态栏右侧自动刷新速率；「计数清零」重置。

## 设置保存位置

- 默认：`%AppData%\SerialTool\settings.json`（关闭程序时自动保存串口参数、连接类型与网络参数、转发设置、Modbus 主站参数、多端口列表、曲线窗口、选项、协议模式、波形窗口、脚本内容、校验算法、高亮/自动回复规则与开关、主题、发送内容、历史、快捷指令、窗口大小）
- 便携模式：在 `SerialTool.exe` 同目录下新建一个空的 `settings.json`（内容写 `{}`），以后设置就保存在 exe 旁边
- 程序出错时的详细信息写在同目录的 `error.log`

```
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o publish

dotnet publish -c Release -f net6.0-windows -r win-x64 --self-contained false ^
```


## 已知限制（v1.3）

- 多会话采用「多端口监视」页而非“每个会话一整套界面”的标签页：主界面的发送、脚本、自动回复、Modbus 主站、波形、曲线等都绑定在一个主连接上，整体复制成多标签风险大、容易出错；多端口页可同时打开任意多个串口、合并着色显示并选择端口发送，但多端口里的端口不参与脚本 / 自动回复 / Modbus 主站 / 曲线（这些只用主连接）
- 普通文本视图中的查找只选中当前匹配（无法给 TextBox 内所有匹配上色）；开启过滤或高亮后的行视图会高亮全部匹配
- Modbus 主站一次只执行一个请求；RTU 透传 TCP/UDP 时按 RTU 帧解析，直连 Modbus TCP 设备需把帧格式切到“Modbus TCP”
- 曲线只解析主连接收到的文本行（每行最多 16 个通道）；HEX / 二进制协议的数据请用 Modbus 主站或波形
- 串口转发是纯透传，不做协议转换（如 Modbus TCP ↔ RTU）
- UDP 单包最大 65507 字节，超过会自动分包
